    子弹的对象的创建

实现过程:
    大体上采取Python的class用法：属性+方法

移动方法：
    1.黑矩形填充
    2.保存并删除原图片，再在新位置粘贴

创造子弹方法：
    在Enemy_Tank_RandomMove（）方法中将子弹初始化，给子弹的位置属性x和y赋值，direction属性（还需在子弹的结构体中加入direction属性）需要确定，在Enemy_Tank_RandomMove（)
方法中给子弹结构体的direction属性赋值（赋个1,2,3,4),之后即可将完整的子弹对象传入Bullet方法中，进去一个子弹对象就保存一个，若子弹超出边界就给它的live属性赋值False，删除它。

方法1.先对子弹的live属性进行判断，若是True，先执行移动方法后再对子弹的位置进行判定，若越界，live变成False，一旦变成False，就删除（如何删除）
方法2.创造一个存子弹坐标的二维数组arr[20][2][4]（第一列是子弹标记，第二和第三列是坐标）存位置，再创造一个存图片的IMAGE* 数组存对应的图片,将两个数组通过下标进行一一对应
方法3.创建结构体类型的数组存储生成的子弹对象，对每个子弹对象都调用移动方法

子弹越界考虑了两种方法：
    1.只要越界DODGE_BULLET_NUMBER++；但是当子弹越界时，还会对此是否越界进行判断，就造成结果太大
    2.每个子弹对象再添加一个Is_Over属性，若越界变成True，最后对子弹数组中的每个子弹对象的Is_Over属性进行遍历，得出结果

子弹反弹考虑了两种方法：
    1.给每个子弹对象附上speed和bounce属，例如一个子弹的发射方向向上，当将要越界时将其direction属性赋值2，方向相反向下移动，通过bounce++从而限制反弹次数（但是有时会
某一子弹与之前的子弹发生重叠问题，可以试试saveimage和putimage解决）
    2.speed变成负数不好用

 碰撞方法：
